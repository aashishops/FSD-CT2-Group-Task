# Team Management Application

A full stack application for managing team members with React frontend, Node.js/Express backend, and MongoDB database.

## Features

- Add new team members with profile images
- View all team members
- View detailed information about each member
- Responsive design

## Technologies Used

- Frontend: React.js, React Router, Axios
- Backend: Node.js, Express.js
- Database: MongoDB
- File Upload: Multer

## Installation

1. Clone the repository:
```bash
git clone https://github.com/aashishops/FSD-CT2-Group-Task.git
cd FSD-CT2-Group-Task
cd Client && npm install
cd ..
cd Server && npm install
cd ..
npm run dev
```
